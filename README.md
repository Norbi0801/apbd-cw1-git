# GitPractice

Prosta aplikacja konsolowa w C#, która liczy podstawowe statystyki dla tablicy liczb: sumę, średnią, liczbę elementów i maksimum.

## Wymagania

- [.NET SDK 10.0](https://dotnet.microsoft.com/download) lub nowszy

Wersję zainstalowanego SDK sprawdzisz poleceniem:

```bash
dotnet --version
```

## Uruchomienie

W katalogu głównym repozytorium:

```bash
dotnet run
```

Opcjonalnie możesz najpierw zbudować projekt:

```bash
dotnet build
```
